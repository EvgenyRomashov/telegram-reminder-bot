# Как запускать тесты

Этот проект использует `pytest` для тестирования.

## Установка

1.  Убедитесь, что у вас установлен Python и pip.
2.  Установите зависимости для разработки:
    ```bash
    pip install -e ".[dev]"
    ```

## Запуск тестов

Чтобы запустить все тесты в проекте, выполните следующую команду в корневой директории:

```bash
pytest
```
